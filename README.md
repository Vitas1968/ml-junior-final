# Credit Risk Management Model

Итоговый проект курса **Machine Learning Junior**.  
Проект посвящён построению модели машинного обучения
для оценки вероятности дефолта клиента по кредиту.

---

## Задача

Решается задача **бинарной классификации**:  
предсказание факта дефолта клиента (`flag = 1`).

Под дефолтом понимается ситуация,
когда заёмщик допускает длительную просрочку по кредитным обязательствам.

Каждая строка итогового датасета соответствует **одному клиенту** (`id`).

---

## Данные

Исходные данные:
- представлены в формате **Parquet**;
- имеют большой объём и обрабатываются итеративно;
- содержат агрегированную кредитную историю клиентов.

Целевая переменная (`flag`) хранится в отдельном файле
и объединяется с признаками по `id`.

Исходные данные не включены в репозиторий из-за ограничений по объёму.

Описание признаков приведено в файле `description.xlsx`.

---

## Подход

В рамках проекта реализован полный ML-pipeline:

- загрузка и агрегация исходных данных;
- генерация признаков (Feature Engineering);
- обучение и сравнение нескольких моделей;
- выбор и обучение финальной модели;
- воспроизводимый pipeline обучения;
- инференс по конкретному пользователю.

Подробное описание архитектуры, экспериментов и логики решений
приведено в файле **[`PROJECT_FLOW.md`](PROJECT_FLOW.md)**.

---

## Используемые модели

В ходе работы были протестированы:
- Logistic Regression (baseline);
- Decision Tree;
- Random Forest;
- LightGBM;
- CatBoost (диагностически).

Финальной моделью выбран **LightGBM**,
показавший наилучшее качество после Feature Engineering.

---

## Качество модели

- Тип задачи: бинарная классификация  
- Основная метрика: **ROC-AUC**  
- Финальное качество на тестовой выборке:  
  **ROC-AUC ≈ 0.7363**

Причины недостижения порога ROC-AUC ≥ 0.75
подробно разобраны в `PROJECT_FLOW.md`.

---

## Инференс

Реализован CLI-инференс по конкретному пользователю (`id`):

- пользователь выбирает `id`;
- модель возвращает вероятность дефолта в процентах;
- даётся текстовая интерпретация уровня риска
  (низкий / умеренный / высокий / критический).

Пример:
> Вероятность дефолта пользователя с id=1221701 примерно 41.47 % и имеет умеренный риск.
