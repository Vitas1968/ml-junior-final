# Credit Risk Management Model

Итоговый проект курса **Machine Learning Junior**.  
Проект посвящён построению модели машинного обучения для прогнозирования дефолта по кредиту.

---

## Задача

Решается задача **бинарной классификации** — предсказание факта дефолта клиента.  
Под дефолтом понимается ситуация, когда заёмщик не совершает платежи по кредиту более 90 дней.

Каждая запись в данных соответствует одному кредитному продукту конкретного заёмщика.

---

## Данные

Данные содержат информацию о кредитных продуктах, платёжной истории и финансовых показателях клиентов.  
Формат данных — **Parquet**, объём данных значительный, поэтому обработка выполняется **итеративно**, без загрузки всего датасета в память.

Целевая переменная хранится отдельно.  
Описание признаков приведено в файле `description.xlsx`.

Исходные данные не включены в репозиторий из-за большого объёма.

---

## Подход

В рамках проекта выполнены следующие этапы:
- анализ структуры данных;
- генерация и отбор признаков;
- обучение и сравнение нескольких моделей классификации;
- подбор гиперпараметров лучшей модели;
- построение воспроизводимого `sklearn.pipeline`;
- сохранение обученной модели и предсказаний.

---

## Качество модели

- Тип задачи: бинарная классификация  
- Основная метрика: **ROC-AUC**  
- Достигнутое значение на тестовой выборке: **ROC-AUC ≥ 0.75**

Переобучение контролировалось с помощью разбиения данных и кросс-валидации.
